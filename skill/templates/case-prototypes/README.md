# Case-derived Prototype Record

This directory stores metadata only. Prototype records must reference the
single source case directory; do not copy PPTX, PNG, PDF, SVG, or other binary
assets here.

A valid record must identify `case_id`, `slide_ids`, `case_root`, source and
preview paths, Recipe, object map, license status, context permission, and
redaction status. Missing provenance or permission keeps the record out of the
runtime candidate set.
