# Brief acceptance contract

| ID | Requirement | Visible evidence expected in PNG | Priority |
|---|---|---|---|
| R1 | 面向管理层，形成批准执行的行动共识 | 页面围绕压力、选择、指标、节奏和行动收束 | MUST |
| R2 | 共 6 页、16:9 | 结构报告显示 6 页，页面比例为 16:9 | MUST |
| R3 | 体现 2026 增长落后行业与 2027 目标 | 有清晰可读的对比数据和目标关系 | MUST |
| R4 | 呈现三项战略选择 | 三项战略名称和作用清晰可区分 | MUST |
| R5 | 呈现四季度执行节奏 | 有明确的 Q1–Q4 时间线或阶段结构 | MUST |
| R6 | 深墨色 + 青绿色主强调色，橙色仅用于风险 | 全 deck 色彩角色一致，无随机多色 | MUST |
| R7 | 会议投影可读 | 无溢出、遮挡、过小正文、不可读图表 | MUST |
| R8 | 页面结构有变化 | 至少包含封面、数据页、战略页、时间线、行动收束等不同页面角色 | SHOULD |
| R9 | 核心内容保持可编辑 | 文字、数字、图表、形状不是整页截图 | MUST |
| R10 | 不额外编造精确指标 | 仅使用给定数据，其他表述为定性判断 | MUST |
| R11 | 达到交付级视觉完成度 | 页面节奏、主视觉、版式关系和视觉差异不能停留在普通模板水平 | MUST |

## Pass rule

All `MUST` rows must pass. Any overflow, clipping, unreadable chart, invented
precise metric, or failure to show the requested narrative is a blocker.
