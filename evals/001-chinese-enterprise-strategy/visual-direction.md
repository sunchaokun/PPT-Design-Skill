# Visual direction

- Mode: Build Mode
- Domain: business / enterprise strategy
- Audience: company management team
- Variance: 6/10; use distinct page roles without random layout changes
- Motion: 2/10; static deck must work in PDF and PNG
- Density: 5/10; data pages are structured, opening and close are spacious
- Background: near-black navy `#0F172A`
- Primary accent: teal `#14B8A6`
- Risk accent: orange `#F97316`, only on the diagnosis/risk statement
- Text: near-white `#F8FAFC`, secondary slate `#CBD5E1`, muted `#94A3B8`
- Typography: large CJK-safe headings, body text no smaller than 16 pt where
  possible, no decorative font dependence
- Grid: 0.7-inch safe margins, consistent left alignment, generous gaps
- Images: none required; use editable geometry and charts for this test
- Forbidden: default blue, rainbow palette, repeated KPI card rows, dense
  unedited bullet walls, fabricated exact data
