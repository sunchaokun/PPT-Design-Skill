# Acceptance contract

| ID | Level | Requirement | Evidence |
|---|---|---|---|
| R1 | MUST | 12-page, 16:9 editable PPTX | Structural inspection and slide count |
| R2 | MUST | Clear architecture thesis rather than a feature list | Slides 1–3 and 12 establish and close the argument |
| R3 | MUST | At least five distinct agent patterns shown as editable diagrams | Slides 5–9 |
| R4 | MUST | Governance, permissions, observability, and evals are part of the system | Slides 10–11 |
| R5 | MUST | No invented customer claims or unsupported precise metrics | Copy review and source notes |
| R6 | MUST | Dark blueprint system is consistent and readable at 1280×720 | PNG review of every slide |
| R7 | SHOULD | Page structures vary intentionally | Cover, framework, architecture, sequence, matrix, loop, close |
| R8 | SHOULD | Source boundary is visible without overwhelming the story | Footnotes on source-dependent slides |
| R9 | NICE | Speaker-ready final slide with a memorable design principle | Slide 12 |
