# Flagship Case 004: AI Agent Operating System

## Brief

Create a 12-page, 16:9 English technical editorial deck titled **AI Agent
Operating System**. The deck is for engineering leaders, product architects,
and technical decision makers evaluating agentic systems.

The audience should leave with a practical design thesis: choose the smallest
architecture that can carry the work, then add routing, parallelism,
orchestration, evaluation, observability, and human control only where the
problem requires them.

## Content boundary

The deck explains conceptual architecture patterns and decision criteria. It
does not claim production performance, customer results, or benchmark numbers.
Any quantitative-looking values are explicitly labeled illustrative.

## Required capability proof

- Native editable architecture diagrams with connectors and nested system
  boundaries;
- Multiple page architectures, not a repeated card grid;
- Technical chart / decision matrix with readable labels;
- Clear distinction between workflow, agent, multi-agent, and governance;
- Source notes referencing Anthropic's public agent architecture and evaluation
  guidance;
- Dark blueprint visual system with cyan, lime, and amber semantic accents;
- Presentation-scale readability and a complete takeaway on every page.
