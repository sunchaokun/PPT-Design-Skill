# Visual direction

## Direction: Electric Blueprint / Control Room

The deck treats agent architecture as a living operating system, not as a
collection of software feature cards. The visual language combines technical
blueprint geometry with an editorial control-room rhythm:

- Deep navy-black field with a faint blueprint grid;
- Cyan for system structure and user intent;
- Lime for valid flow, hand-offs, and passing evaluation;
- Amber for human approval and risk boundaries;
- Coral only for blocked or failed paths;
- Monospace labels for system names and metadata;
- Large condensed-style statements paired with precise micro labels;
- Thin connectors, nested boundaries, and numbered pattern pages;
- No decorative gradients, stock photos, or generic KPI cards.

## Dials

- Variance: 8/10 — each pattern earns a different diagram architecture;
- Motion: 4/10 — static directional cues imply motion without relying on unsupported animation;
- Density: 7/10 — technical but controlled, with one dominant diagram per page.

## Visual thesis

**Autonomy is not a mood. It is a system boundary.**

Every page should make a relationship visible: a choice, a hand-off, a loop, a
boundary, or a trace.
