# Visual direction

**Visual thesis:** A nocturnal cultural landmark transitions into a luminous
museum-city, using geometry only as a quiet structural language.

**Palette:** deep blue-black, warm paper, silver-grey, restrained brass gold.

**Typography:** English only; Georgia for architectural editorial display text,
Arial Narrow for metadata and factual labels, Arial for supporting copy.

**Component language:** thin brass rules, small uppercase metadata, native SVG
line studies, and large but visually subdued data figures.

**Forbidden:** generic card grids, repeated left/right split pages, stretched
photography, high-contrast decorative geometry, and excessive overlays.
